# OLED 黑屏保护

一个给 OLED 屏幕"放假"的小工具。

## 这是什么

OLED 屏幕长时间显示同一个画面会烧屏——任务栏、桌面图标、常驻窗口的位置会留下永久的残影。因为 OLED 每个像素自己发光，用久了亮度会不均匀。

这个工具做的事很简单：双击运行，3 秒后屏幕变全黑，让像素彻底休息。黑色状态下 OLED 像素是不发光的，等于给屏幕放了个假。

## 功能

- 双击运行，倒计时 3 秒后进入全屏纯黑
- 黑屏状态下，移动鼠标、按任意键、或点一下鼠标都能退出
- 黑屏期间会阻止电脑自动休眠，退出后自动恢复正常
- 窗口带一点淡入淡出的动画，倒计时数字也会呼吸式地渐隐渐现

就这些，没别的了。不装服务、不常驻后台、不联网、不留垃圾。

## 怎么用

直接双击 `Start_OLED_BlackScreen.bat` 就行。

等 3 秒，屏幕变黑，人走开。回来动一下鼠标就恢复了。

如果你不想看到双击时闪一下命令行黑框，用 `Start_OLED_BlackScreen.vbs` 启动，它会在后台静默运行。

## 三个文件都是干嘛的

| 文件 | 作用 |
|------|------|
| `OLED_BlackScreen.ps1` | 主程序，所有逻辑都在这里 |
| `Start_OLED_BlackScreen.bat` | 命令行启动器，双击用这个 |
| `Start_OLED_BlackScreen.vbs` | 静默启动器，不闪黑框，适合开机自启 |

## 环境要求

Windows 10 或 11，自带 PowerShell 就能跑，不用装任何东西。
